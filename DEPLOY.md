# Publicação na Vercel

Esta pasta é uma apresentação estática: não há instalação de dependências nem etapa de build.

## Pelo painel da Vercel

1. Importe o repositório que contém esta pasta.
2. Nas configurações do projeto, mantenha a raiz do repositório (`./`) como **Root Directory**.
3. Use **Other** como framework e deixe os comandos de instalação e build vazios.
4. Publique e abra o endereço gerado para conferir os slides e as animações.

## Pela CLI

Em um terminal autenticado na Vercel, execute `vercel` dentro desta pasta para criar uma prévia. Após revisá-la, execute `vercel --prod` para publicar em produção.

As imagens do QScratch e os arquivos de estilo estão nesta pasta. As animações usam o player e os arquivos hospedados externamente, portanto precisam de conexão com a internet. Confira sua reprodução no endereço publicado. As imagens do QScratch vêm do artigo de Escanez-Exposito et al. (2025), DOI 10.1140/epjqt/s40507-025-00314-9. As animações são de Christine Somkunwar, disponibilizadas no LottieFiles sob a Lottie Simple License; confira suas condições para a publicação pretendida.
